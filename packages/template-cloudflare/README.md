# Terrarium Tickets on Cloudflare

Self-contained, deployable application source generated by the Terrarium control plane. The unauthenticated sample API is intentionally public for this real-deploy spike.

## Commands

```sh
pnpm install
pnpm run deploy
pnpm run destroy
```

`deploy` requires Cloudflare credentials understood by Alchemy (`CLOUDFLARE_ACCOUNT_ID` plus either `CLOUDFLARE_API_TOKEN`, or an authenticated Alchemy profile). Configuration: `WORKER_NAME`, `D1_DATABASE_NAME`, and `STACK_NAME` (all have per-app values supplied by the scaffold).

The Worker hosts the Tickets model on Cloudflare Durable Objects. Its D1 migration provisions `app_metadata`; `GET /d1-health` proves the binding. Commands, queries, and MCP are unauthenticated for this spike.

```sh
curl "$WORKER_URL/health"
curl "$WORKER_URL/d1-health"
curl -X POST "$WORKER_URL/OpenTicket" -H 'content-type: application/json' \
  -d '{"target":"demo-1","input":{"title":"Real deployment","reporter":"demo"}}'
curl "$WORKER_URL/TicketById/demo-1?stream=Ticket%2Fdemo-1&version=1"
```
