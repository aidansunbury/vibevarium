1 — the growth cycle

i.

Plant a seed

One command — vibevarium grow my-app — or one click in the control plane. Every app starts from the same seed: a React SPA + typed Effect backend, so the contract never varies, only the starting shape.

ii.

It comes up on its own

GitHub repo, Cloudflare Worker + D1 database, custom domain, and a registered OIDC auth client — scaffolded in minutes, discovered by the platform automatically. No YAML, no console spelunking.

iii.

Tend the garden

Provision, inspect, and prune from platform.vibevarium.com. One platform token opens the gateway and every app; per-app grants revoke cleanly. Humans and agents share the same vibevarium CLI.

2 — anatomy of a grown app

radix · roots

Its own repo

Every app is a real GitHub repository from minute one — history, CI, and collaborators included. Fork the shape, keep the contract.

caulis · stem

Its own deploy

A Cloudflare Worker + D1 database per app, on its own hostname. Apps scale to zero and wake on demand; no shared blast radius.

folium · leaves

Its own auth

An OIDC client registered at deploy time. One platform token opens every app — with per-app grants you can revoke in the control plane.

flos · bloom

One gateway

The meta-MCP aggregates every app's tools into a single gateway, so agents see one interface while each app stays self-contained.

sucus · sap

Connections

Connect a provider once; per-app tokens are vended through a unified credential proxy, and revoking cascades. The plumbing stays out of your code.

hortus · garden

One control plane

The gardener at platform.vibevarium.com: provision, inspect, prune — a field guide to everything growing.

4 — horticultural principles

  • Grown, not built. Apps aren't assembled from parts — they're raised from a seed with the shape already inside. You prune and train; you don't pour concrete.
  • Each world, self-contained. A vibevarium jar has its own soil, water, and air. An app has its own repo, deploy, and auth. Nothing leaks between jars.
  • One gardener, many jars. The control plane sees every app, every token, every connection — and the meta-MCP hands agents the same view.
  • Agents are first-class gardeners. The CLI composes app CLIs and MCP tool schemas so humans and agents tend the garden through one interface.
